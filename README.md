# Ubo Documentation

Source for [docs.getubo.com](https://docs.getubo.com/), built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/).

## Local Development

1. Start the dev server:

   ```bash
   uv run mkdocs serve
   ```

2. Open [http://localhost:8000](http://localhost:8000) in your browser. Changes to the markdown files will auto-reload.

## Deployment

The site is automatically deployed to GitHub Pages on every push to `main` via GitHub Actions.
